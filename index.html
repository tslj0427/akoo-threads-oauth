阿酷 Threads OAuth 測試頁

這個公開頁只負責接住 Meta / Threads 的授權回傳。它不要求密碼、不儲存 App Secret、不交換 access token。

Meta 後台請填這個 Redirect URI

https://tslj0427.github.io/akoo-threads-oauth/auth/callback/

Meta 後台的「有效的 OAuth 重新導向 URI」必須與這個網址完全相同，包含最後的斜線。

要測 threads_content_publish，請從本機工具開始

發文權限需要 App Secret 換 token，所以正式測試要先打開本機頁面，再由本機頁面跳去授權。

http://127.0.0.1:8787/
正確流程：本機測試器 → Meta 授權頁 → 這個公開 callback → 自動轉回本機測試器 → 預覽 → 使用者確認發布。

只測 OAuth 跳轉

如果你只是想確認 App ID 與 Redirect URI 是否能跳轉，可在這裡貼 App ID。這個按鈕不會交換 token，也不能完成發文測試。

這個公開測試頁不讀取 Threads 密碼、不自動發文、不自動回覆。App Secret 請只輸入在本機測試器，不要貼在這裡。

Demo 影片要拍到的重點

  • 本機工具顯示要使用 threads_basic 與 threads_content_publish。
  • 使用者自己點「連接 Threads 帳號」。
  • 畫面跳到 Meta / Threads 官方授權頁。
  • 授權完成後回到固定 callback，再轉回本機工具。
  • 本機工具先顯示預覽，使用者按確認後才發布測試貼文。
