阿酷 Threads OAuth 測試頁

這個頁面用來測試 Threads 帳號授權。它只會建立 Meta / Threads 官方授權網址，不會要求密碼，也不會儲存 App Secret。

Meta 後台請填這個 Redirect URI

https://tslj0427.github.io/akoo-threads-oauth/auth/callback/

Meta 後台的「有效的 OAuth 重新導向 URI」必須與這個網址完全相同。

連接 Threads 帳號

請貼上 Meta 後台顯示的 Threads App ID。App ID 不是 Secret，可以出現在這裡；App Secret 不可以貼在這個頁面。

這個測試頁不讀取 Threads 密碼、不自動發文、不自動回覆。授權完成後會回到 callback 頁，收到授權碼後再由本機安全流程交換 token。

Demo 影片要拍到的重點

  • 使用者自己貼上 Threads App ID。
  • 使用者自己點「連接 Threads 帳號」。
  • 畫面跳到 Meta / Threads 官方授權頁。
  • 授權完成後回到固定 callback 頁。
  • 頁面說明不讀取密碼、不自動發文、不自動回覆。
